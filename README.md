Чат на сокетах

В этой работе сделан простой чат с использованием Python и TCP-сокетов

Сервер может работать сразу с несколькими клиентами. Для этого используется threading

В проекте есть три основных файла

server.py отвечает за работу сервера и подключение клиентов

client.py используется для подключения к серверу и отправки сообщений

protocol.py отвечает за формат сообщений

Для запуска сначала нужно запустить server.py

После этого можно запустить несколько раз client.py

При подключении пользователь вводит своё имя

Доступны команды:

/list показывает подключённых пользователей

/quit завершает работу клиента

Обычный текст отправляется другим пользователям

Для передачи сообщений используется свой формат:

COMMAND + LENGTH + DATA

COMMAND содержит команду размером 4 байта

LENGTH содержит размер сообщения

DATA содержит само сообщение

Так как TCP передаёт данные как поток байтов, для получения сообщения используется recv_exact()

Также в программе предусмотрена обработка отключения клиентов. Сервер продолжает работать, если один из клиентов отключился
